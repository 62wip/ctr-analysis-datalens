# Анализ и визуализация данных с использованием Yandex DataLens: исследование по прогнозированию CTR

Данный репозиторий содержит исходный код, скрипты и текст курсовой работы, посвященной предсказанию кликабельности (CTR) мобильной интернет-рекламы и бизнес-аналитике результатов алгоритмов машинного обучения.

## 🔗 Ссылки
- **Интерактивный дашборд**: [Yandex DataLens](https://datalens.yandex/ly2b9cjdtuhy5)
- **Набор данных**: [Avazu Click-Through Rate Prediction (Kaggle)](https://www.kaggle.com/competitions/avazu-ctr-prediction/data)

## 🛠 Стек технологий
- **Machine Learning & Data Processing**: Python, Pandas, NumPy, CatBoost.
- **Базы данных**: [ClickHouse](https://clickhouse.com/).
- **BI & Визуализация**: [Yandex DataLens](https://datalens.ru/).
- **Оформление отчета**: [Typst](https://typst.app/).

## 📂 Структура репозитория

* `code/` — Python скрипты, Jupyter ноутбуки на Python для предобработки данных, загрузки датасета в ClickHouse и обучения модели CatBoost.
  * `code/catboost/` — код обучения и генерации предсказаний (submission) для соревнования Kaggle.
  * `code/data_extraction_for_report/` — скрипты посторения необходимых графиков и таблиц, используемых в отчете.
* `typst/` — исходные файлы отчета курсовой работы, написанные на языке верстки Typst.

## 🎯 Основные этапы работы

1. **Разведочный анализ данных (EDA)** масштабного датасета мобильной рекламы Avazu, насчитывающего более 40 млн уникальных записей и собранного за 10 дней с естественным дисбалансом классов (около 17% кликов).
2. **Предобработка больших данных** с использованием подхода Out-of-Time (OOT) валидации и локального батчевания файлов, которые физически не помещаются в оперативную память.
3. **Обучение модели CatBoost** для решения задачи бинарной классификации (предсказания вероятности клика). Модель обучалась с использованием GPU на платформе Kaggle, достигнут высокий результат по метрике LogLoss (~0.3831 на валидации).
4. **Работа с ClickHouse** — развертывание колоночной аналитической СУБД для обеспечения высокой скорости выполнения запросов из BI-системы.
5. **Проектирование и сборка BI-дашборда** в Yandex DataLens. Создана многостраничная модульная архитектура, идейно разбитая на 3 модуля:
   - Продуктовые показатели рекламы и бизнес-метрики.
   - Разведочный анализ данных (EDA) и структура набора данных.
   - Оценка качества модели CatBoost и визуальная интерпретация важности признаков.

## 🚀 Запуск проекта

#### Клонирование репозитория

```bash
git clone https://github.com/62wip/ctr-analysis-datalens.git
cd ctr-analysis-datalens
```

#### Установка зависимостей

```bash
cd code
pip install -r requirements.txt
```

Теперь можно запускать все скрипты проекта.

#### Работа с Jupyter Notebook

Все части EDA, подготовки данных и обучение модели CatBoost выполняется в Jupyter Notebook-файлах (`.ipynb`), расположенных в директории `code/`. Их необходимо запускать после клонирования репозитория локально или с иcпользованием облачных сервисов для работы с Jupyter Notebooks.
